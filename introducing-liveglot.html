为了听懂英文 Trading Room，我开发了一款实时字幕翻译软件 Liveglot

引言

学了一年多的价格行为学（Price Action），最近我终于付费进了 PA 的英文 Trading Room，想跟着看看老外实盘到底是怎么分析、怎么找入场和止损的。

钱是付了，进去以后才发现最大的问题不是看不懂 K 线，而是听不懂。讲师语速本来就快，里面又夹着一堆交易术语和盘口俚语，经常一句话没反应过来，后面两三句已经过去了。

我在网上找了一圈直播实时翻译软件，用下来都不太满意。干脆自己动手，做了一款专门看外语直播和网课的 Mac 工具：Liveglot。

  • 官网地址：liveglot.app/zh-hans

为什么自己写一个

市面上能做实时翻译的工具其实不少，但真拿来看 Trading Room 这种场景，总会卡在几个地方：

一个是贵，动不动就是按月订阅，每个月几十美金，算下来比我买课程和 API 还贵。另一个是翻译太碎，很多软件是识别到几个词就往外蹦翻译，英文语序和中文语序又不一样，译文读起来支离破碎，看着比听原文还累。

还有一点我特别需要，但一直没找到顺手的：看直播的时候，漏听了一句或者没跟上字幕，我想立刻问一下刚才讲师到底说了什么。

我自己平时就在折腾工具，索性按照自己看盘、听课的习惯写了 Liveglot。目前它只做这一件事：听 Mac 上正在播放的声音，实时出双语字幕，顺便让你能随时问 AI。

我最常用的几个功能

Liveglot 采集的是 Mac 的系统声音（也支持麦克风），所以只要能出声的地方都能用——浏览器里的直播、Zoom、YouTube、Twitch 都行。

整句翻译，带上下文

讲师说话的时候，Liveglot 不会把半句话拆得稀碎，而是等一句话说完再翻，同时把前面几句的上下文一起交给模型。这样出来的中文译文会通顺很多，看一眼就能跟上思路。

没听懂或者漏了，直接在旁边问 AI

这是我自己用得最多、也最满意的功能。看直播很难做到全程 100% 集中，有时候切出去看一眼图表或者走个神，回来就不知道讲师在说哪个价位了。

Liveglot 右侧带了一个聊天面板，回答只依据当前这场直播的字幕记录，不会自己瞎编。你可以直接问「刚才说的关键价位是多少」「总结一下最近几分钟讲了什么」，也可以右键点击某一句字幕，直接引用到聊天里追问。

自动保存成 Markdown 笔记

每一场听完，软件都会自动把带时间戳的中英文对照记录保存成 .md 文件。我自己习惯用 Obsidian，直接丢进去就能留着复盘，不用再手动截图或者抄笔记。

一次买断，用自己的模型和 Key

我不太喜欢把简单工具做成按月扣费的订阅制，所以 Liveglot 直接做了买断制：

  • 软件价格：$19.99 一次买断，终身使用，包含后续所有更新，最多可以在两台 Mac 上激活；
  • 七折优惠：可以直接用优惠码 LIVEGLOT-VMXWXC 在购买页下单，有效期到 2026 年 12 月 31 日；
  • 免费试用：可以先下载免费试用 7 天，不用绑卡，觉得顺手再买；
  • 系统支持：目前支持 macOS 14 及以上、Apple 芯片（M1 及以后） 的 Mac，Windows 版还在开发中。

至于平时使用产生的语音识别和翻译费用，全部由你自己掌控，中间不经过我的服务器：

语音识别可以完全免费。 软件内置了本地模型管理，设置里点一下「下载」，就能把 Whisper 模型（比如推荐的 Large v3 Turbo 或更轻量的 Small）装到自己电脑上，不用敲命令，也不花钱。如果你想要更快的云端识别速度，也可以填自己的 Soniox API Key。

翻译和聊天接你自己的 API Key。 支持 OpenAI、DeepSeek、OpenRouter，也支持本地的 Ollama，或者任何兼容 OpenAI 格式的接口。用自己的 Key 非常便宜，正常听一两个小时的直播课，API 费用也就几美分。所有 Key 都存在 macOS 钥匙串里，没有账号体系，也不用担心隐私。

最后

Liveglot 最初就是为了解决我自己听不懂 PA Trading Room 的问题做出来的。这段时间我自己每天挂着它听课、看盘，整体用下来已经很顺手了，至少不再因为语言卡壳而错过关键分析。

如果你也在看外语的 Trading Room、英文网课或者直播，遇到过类似的语言障碍，可以去 liveglot.app/zh-hans 下载试用 7 天看看。使用过程中有什么问题，或者觉得哪里不好用，随时联系我反馈。
