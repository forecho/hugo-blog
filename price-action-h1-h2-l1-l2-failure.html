Price Action 进阶：如何用 H1/H2 与 L1/L2 的「失败」，提前看穿趋势与震荡切换

引言

刚开始学 Al Brooks 价格行为学（Price Action）时，大多数人最先上手的入场工具就是数 K 线（Bar Counting）——多头回调找 H1 / H2 挂单做多，空头反弹找 L1 / L2 挂单做空。

但实盘里经常碰到让人很难受的场面：你在一段看似不错的上涨趋势里等来回调，在 H1 高点挂 Buy Stop 进场，结果刚成交，下一根 K 线立刻收出大阴线把你按在山顶；你不信邪，等行情走出两腿回调出现 H2 再进一次，结果又被反向砸穿止损。

这种连亏并不是数 K 线失效了，而是市场环境已经悄悄切入了震荡区间（Trading Range）。

在价格行为学里，H1/H2 和 L1/L2 不只是顺势入场点，它们的失败（Failure）更是判断市场换挡最直接的信号——说明原有的单边惯性正在瓦解。

核心逻辑：用失败识别环境切换

想看懂信号为什么会失效，先要记住 Al Brooks 最核心的市场惯性定律：

在趋势中，80% 的反转会失败；在震荡区间中，80% 的突破会失败。

把这句话对应到盘面的 H1/H2 与 L1/L2 上，市场状态其实就分三种：

  1. 趋势延续期：顺势回调信号（多头 H1/H2、空头 L1/L2）走得很顺。价格突破信号 K 线后迅速脱离成本区，很少回头测试防守底线。
  2. 趋势转震荡（Regime Change）：一旦顺势信号开始频繁出现「刚触发就被反向砸穿」，说明对手盘不再只是获利了结，而是开始在极值附近逆势阻击，市场大概率已经切入震荡区间。
  3. 震荡转趋势：反过来，当震荡区间边界的突破不再失败，而是顺利走出跟进并推进第二腿时，说明震荡区间即将结束，新的趋势正在成型。

四组形态对比：什么是真正的「失败」？

实战里判断一个信号算不算真失败，核心看两点：

  1. 防守线是否被打穿（信号 K 线的极值点，或两腿回调的结构低点/高点）；
  2. 顺势追突破的人是否被套在了极端位置（Trapped Traders）。

下面把多空四个核心信号的「成功 vs. 失败」逐一对照看一遍。

1. H1 成功 vs. H1 失败（多头初次回调）

H1（High 1）是上升趋势回调中，第一次尝试恢复上涨、突破前一根 K 线高点的多头信号。

  • H1 成功（顺势延续）：突破信号 K 高点触发 Buy Stop 后，多头迅速推高，紧跟大实体阳线拉开成本区，信号 K 低点防守线始终未被回测。
  • H1 失败（诱多被套）：刚触发买入就缺乏跟进（Lack of Follow-through），紧接着被大阴线反向吞没并跌破信号 K 低点，高位追多的交易者直接被套。

2. H2 成功 vs. H2 失败（多头两腿回调）

健康趋势里，H1 失败其实很常见——市场经常需要走完两腿回调（ABC 结构）清洗浮筹，这就形成了胜率更高的 H2（High 2，常见形态就是双底牛旗）。

  • H2 成功（两腿洗盘结束）：价格完成两腿回调测试双底不破，强阳线突破 H2 信号高点，顺势开启下一段主升浪。
  • H2 失败（趋势瓦解）：连最稳健的两腿回调结构在触发进场后都被大阴线砸穿双底低点，说明原有单边多头惯性基本失效，这时别再急着抄底接飞刀。

3. L1 成功 vs. L1 失败（空头初次反弹）

空头逻辑与多头完全镜像。L1（Low 1）是下跌趋势反弹中，第一次尝试恢复下跌、跌破前一根 K 线低点的空头信号。

  • L1 成功（顺势下跌）：跌破信号 K 低点触发 Sell Stop 后，空头迅速向下加速，反弹高点防守位未被触及。
  • L1 失败（诱空被套）：跌破触发后立刻遭遇强买盘托举，大阳线直接拉起并反穿反弹高点，低位追空的交易者被套（Trapped Bears），很容易引发一轮轧空。

4. L2 成功 vs. L2 失败（空头两腿反弹）

L2（Low 2）是下降趋势里经历两腿反弹（双顶熊旗）后的二次做空信号。

  • L2 成功（双顶续跌）：两腿反弹遇阻衰竭，跌破 L2 信号低点后顺畅展开第二腿主跌浪。
  • L2 失败（趋势终结）：L2 触发后完全跌不动，反而被强阳线直接突破整个双顶反弹高点，说明空头趋势已经走坏，盘面正在转向宽幅震荡甚至反转。

实战怎么选：H1/L1、H2/L2 和 Failed H1/L1 分别什么时候用？

价格行为学里没有脱离背景的固定胜率。先判断当前盘面处在哪种环境，再决定用哪一招：

当前盘面背景优先做什么别做什么
强趋势初期 / 紧密通道（刚启动、几乎不回调）直接顺势做 H1 / L1（有 H2 也做）别逆势做 Failed H1/L1
强趋势末端 / 高潮（Sell/Buy Climax）（连走多根巨幅加速 K 线）警惕 Failed L1 / H1（高潮竭尽信号，可减仓或等反转）别在跌最狠/涨最猛的位置盲目追 L1/H1
普通趋势 / 宽通道（回调较深、有来有回）跳过 H1/L1，专做顺势 H2 / L2别急着追 H1/L1，容易被第二腿扫止损
震荡区间边缘（上沿阻力 / 下沿支撑）做 Failed H1/L1 反手剥头皮，或等边缘 H2 / L2别用 Stop 单追边缘突破
震荡区间正中间空仓观望全都不做

几个实盘里最容易踩坑的补充：

  • 常规行情主力是 H2 / L2：市场回调天然爱走两腿（ABC 结构），大多数时候跳过 H1/L1、等双底/双顶后的 H2/L2 胜率更稳（Al Brooks 课程里标准 H2/L2 在 1:1 盈亏比下常评估在 60% 左右）。但行情走到第三腿（Wedge）时，顺势延续概率会明显下降。
  • 别把「强趋势末端的高潮」当成「强趋势初期」：有时候盘面跌得很猛，但紧接着 L1 就直接失败了，背后往往是抛售高潮（Sell Climax）——最后一波恐慌盘出清、空头集中获利了结，此时 L1 失败恰恰是动能见底、准备转入宽幅反弹或震荡的信号（买盘高潮后的 H1 失败同理）。
  • 真正高胜率的「做失败」是顺大势抓对手盘的 Failed H2/L2：比如大空头趋势里，多头反弹做出的 H2 被大阴线直接砸穿，信奉二次入场的多头集体被套，止损盘会直接成为顺势下跌的燃料。

实战应对：当信号开始连续失败，我做这三个动作

看懂信号在失败之后，落到执行上主要做这三个调整：

  1. 把「连续两次失败」当成策略切换开关：如果盘面连续出现两次顺势信号失败（比如 H1 失败后 H2 也失败，或者空头信号接连被打穿新高），立刻停止在高低点挂 Stop Order 追突破，先承认当下已经是震荡区间。
  2. 顺着「被套盘」找限价单位置：突破或 H1/L1 失败后，被套在极端位置的交易者往往只想等价格回到成本区保本离场（Breakeven Exit）。这些位置会变成价格回测的磁力点（Magnet），适合配合限价单（Limit Order）在区间边界博弈反向利润。
  3. 突破单走坏就早跑，不硬扛：顺势突破单进场后的正常预期，是迅速脱离成本区。如果不仅没有跟进，反而立刻收出反向强 K 线吞没，在防守线被彻底砸穿之前就该果断离场，别心存侥幸扛到止损。

总结

交易里最贵的失误，往往不是看错某一次方向，而是在市场已经悄悄换挡时，依然死守上一套剧本。

以后复盘或看盘时，除了找哪里可以买 H1/H2、哪里可以卖 L1/L2，养成顺手多看一眼「谁在被套、信号还灵不灵」的习惯：

  • 顺势信号流畅推进 → 市场还在趋势惯性里，大胆跟随，少理逆势杂音；
  • 顺势信号开始连续失败 → 市场正在切入震荡区间，收起追突破的手，把目光转回区间边界和被套盘的保本离场点。
